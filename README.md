## What it does

`main.ts` writes a single line — the one-line funny new name for a planet, plus the why — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> Renaming Mars 'Reddit' — because it's a cold, dusty wasteland full of arguments and everyone there insists they're right.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
